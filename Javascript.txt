VARIABLES
====================

Variable:
Contenedor de información que apunta a un espacio en memoria.

Notas:
- let y const no sobrescriben variables del objeto global (window).

====================
ARREGLOS (ARRAYS)
====================

- Son objetos que almacenan múltiples valores.
- Se definen con corchetes: []

Ejemplo:

Métodos:

.forEach() -> recorre cada elemento
.push()    -> agrega elemento al final
.unshift() -> agrega elemento al inicio
.pop()     -> elimina el último elemento

.length -> devuelve la cantidad de elementos

====================
PASO DE VARIABLES POR VALOR Y POR REFERENCIA
====================

Por valor:
Se copia el dato, por lo que los cambios no afectan a la variable original.

Por referencia:
Se copia la dirección en memoria, por lo que los cambios sí afectan al valor original.


====================
ROMPER REFERENCIA DE OBJETOS
====================

Consiste en crear una copia independiente de un objeto para evitar modificar el original.
Se puede lograr usando el operador spread u otros métodos de clonación.

====================
SWITCH
====================

Es similar a un if, pero más organizado para múltiples casos.

switch(dia) {
    case 0:
        console.log('Domingo');
        break;
            case 1:
        console.log('Lunes');
}

break:
se usa para detener la ejecución del bloque actual y salir del switch, evitando que se ejecuten los siguientes case.

default:
Se ejecuta si no coincide con ningún case.

====================
FOR, FOR IN Y FOR OF
====================

for (tradicional)
Se usa cuando necesitas control total de la iteración.

for...in
Se utiliza para recorrer claves de objetos.
No recomendado para arrays.

for...of
Se usa para recorrer valores directamente (arrays o iterables).

Resumen rápido:
for: control total
for...in: claves (objetos)
for...of: valores (arrays / iterables)

------------------
DOM - Document Object Model
------------------

DOM:
Poder tener acceso dinámico a través de programación a sus elementos y poder manipularlos.

querySelector:
Se usa para seleccionar el primer elemento del DOM que coincide con un selector CSS, con el fin de poder leerlo o modificarlo desde JavaScript.

innerText:
Se usa para leer o modificar el texto visible de un elemento del DOM, respetando el contenido tal como se muestra en pantalla (sin HTML).

innerHTML:
Se usa para leer o modificar el contenido HTML dentro de un elemento del DOM.

Añadir un botom desde el DOM
- createElement  -> crea el elemento
- innerText      -> agrega texto
- appendChild    -> lo inserta en el DOM
- addEventListener -> agrega comportamiento

1. CREAR EL BOTÓN
const boton = document.createElement('button');

2. AGREGAR TEXTO
boton.innerText = 'Click aquí';

3. AGREGARLO AL HTML (DOM)
document.body.appendChild(boton);

4. (OPCIONAL) AGREGAR EVENTO
boton.addEventListener('click', () => {
  console.log('Hiciste click');
});




CREAR UN INPUT DESDE EL DOM (PASO A PASO)

1. CREAR EL INPUT
const input = document.createElement('input');

2. DEFINIR TIPO (OPCIONAL)
input.type = 'text';

3. AGREGAR PLACEHOLDER (OPCIONAL)
input.placeholder = 'Escribe aquí';

4. AGREGARLO AL HTML (DOM)
document.body.appendChild(input);

5. (OPCIONAL) LEER VALOR
console.log(input.value);

6. (OPCIONAL) DETECTAR CAMBIOS
input.addEventListener('input', () => {
  console.log(input.value);
});


RESUMEN:
- createElement -> crea el input
- type          -> define el tipo
- placeholder   -> texto guía
- appendChild   -> lo agrega al DOM
- value         -> obtiene lo escrito
- addEventListener -> detecta cambios
